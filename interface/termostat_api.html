Termostat Controller — API Dokumentation

Serial JSON API til styring af relæer, PID-termostater og temperaturfølere

Protokol: Serial UART Baud rate: 115200 Format: JSON, newline-termineret (\n) Relæer: 4  |  Termostater: 3  |  Sensorer: 4
Generelt
Alle kommandoer sendes som JSON-objekter termineret med \n. Hvert svar indeholder feltet "success": true/false. Ved fejl returneres desuden "error": "..." med en beskrivelse. Ved succes returneres altid den fulde status (samme som status-kommandoen).

Indeksering: Relæer, termostater og sensorer er 1-indekserede i API'et (1–4 for relæer/sensorer, 1–3 for termostater).
Kommandoer
status

Hent nuværende status

Returnerer den fulde systemstatus uden at ændre noget.

Forespørgsel
{ "command": "status" }
Svar
{ "success": true, "status": { "uptime": 120079, "selectedSensor": 2 }, "relays": [true, false, false, false], "thermostat1": { "temperature": 31.8, "setpoint": 30.0, "heater": false, "state": "Run", "fault": false, "faultCode": 0, "kp": 2.0, "ki": 5.0, "kd": 1.0, "alarmLimit": 5.0, "warningLimit": 2.0, "windowSize": 5000, "manualMode": "pid", "manualPercent": 0.0, "heatPercent": 42.3, "autoThreshold": 0.0 }, "thermostat2": { /* samme struktur */ }, "thermostat3": { /* samme struktur */ }, "sensor4": { "temperature": 22.1, "fault": false, "faultCode": 0 }, "override": false }
Alle kommandoer der ændrer tilstand returnerer samme svarformat som status.

FeltTypeBeskrivelse

setRelay

Sæt relætilstand

Tænder eller slukker et bestemt relæ. Relænummeret er 1-indekseret.

ParameterTypeKravBeskrivelse
relayintPåkrævetRelænummer (1–4)
stateboolPåkrævettrue = tænd, false = sluk
Eksempel — tænd relæ 2
{ "command": "setRelay", "relay": 2, "state": true }
Eksempel — sluk relæ 2
{ "command": "setRelay", "relay": 2, "state": false }
Fejl hvis relay ikke er i intervallet 1–4, eller hvis relay/state mangler.
selectSensor

Vælg sensor til display

Skifter hvilken temperatursensor der vises på TM1637-displayet. Opdaterer også sensor-LED'erne.

ParameterTypeKravBeskrivelse
sensorintPåkrævetSensornummer (1–4)
Eksempel
{ "command": "selectSensor", "sensor": 3 }
Fejl hvis sensor ikke er i intervallet 1–4.
setPID

Konfigurer PID-termostat

Sætter setpunkt og PID-parametre for en termostat. Kun thermostat og setpoint er påkrævet — øvrige parametre opdateres kun hvis de er med.

ParameterTypeKravBeskrivelse
thermostatintPåkrævetTermostatnummer (1–3)
setpointfloatPåkrævetØnsket temperatur i °C
kpfloatValgfriProportional-koefficient (standard: 2.0)
kifloatValgfriIntegral-koefficient (standard: 5.0)
kdfloatValgfriDifferentiations-koefficient (standard: 1.0)
windowSizeulongValgfriPWM-vinduet i ms (standard: 5000)
Eksempel — sæt setpunkt og PID-parametre
{ "command": "setPID", "thermostat": 1, "setpoint": 60.0, "kp": 3.0, "ki": 4.0, "kd": 1.5, "windowSize": 10000 }
Fejl hvis thermostat ikke er i intervallet 1–3, eller hvis thermostat/setpoint mangler.
setLimits

Sæt alarm- og advarselsgrænser

Definerer hvor mange grader over setpunktet der udløser henholdsvis advarsel og alarm. Grænser er delta-værdier (ikke absolutte temperaturer).

ParameterTypeKravBeskrivelse
thermostatintPåkrævetTermostatnummer (1–3)
alarmfloatValgfri°C over setpunkt der udløser Alarm (standard: 5.0)
warningfloatValgfri°C afvigelse der udløser Advarsel (standard: 2.0)
Eksempel
{ "command": "setLimits", "thermostat": 2, "alarm": 8.0, "warning": 3.0 }
setState

Sæt termostat-tilstand manuelt

Overskriver en termostats tilstand direkte. Kan bruges til manuelt at sætte eller nulstille HW Alarm. HW Alarm sættes også automatisk af systemet ved sensorfejl eller temperatur uden for det gyldige interval (−30 – 150 °C).

ParameterTypeKravBeskrivelse
thermostatintPåkrævetTermostatnummer (1–3)
statestringPåkrævet"HW Alarm" eller "clear"

Gyldige tilstande (via API: kun HW Alarm og clear):

TilstandBeskrivelseSættes af
OpvarmningSystemet opvarmer mod setpunktetAutomatisk
RunTemperatur er inden for grænserAutomatisk
AdvarselTemperatur afviger mere end warningLimit fra setpunktAutomatisk
AlarmTemperatur er mere end alarmLimit over setpunktAutomatisk
HW AlarmHardware-fejl — varme slukkes og låses. Sættes automatisk ved sensorfejl eller temperatur uden for −30 – 150 °C. Ryddes med "clear" via API (eller automatisk når sensoren igen er gyldig).Automatisk + API
Eksempel — sæt HW Alarm
{ "command": "setState", "thermostat": 1, "state": "HW Alarm" }
Eksempel — nulstil HW Alarm
{ "command": "setState", "thermostat": 1, "state": "clear" }
Fejl hvis state ikke er "HW Alarm" eller "clear".
setManual

Manuel styring af varmeeffekt

Sætter en termostats driftstilstand. Tilstanden pid gendanner automatisk regulering; off og on slukker/tænder for fuld effekt; percent sætter en fast varmeeffekt; auto aktiverer automatisk trinregulering (se setAuto).

ParameterTypeKravBeskrivelse
thermostatintPåkrævetTermostatnummer (1–3)
modestringPåkrævet"pid", "off", "on", "percent" eller "auto"
percentfloatPåkrævet kun ved mode: "percent"Varmeeffekt i % (0–100)
Eksempel — fast 40% effekt
{ "command": "setManual", "thermostat": 2, "mode": "percent", "percent": 40.0 }
Eksempel — tilbage til PID-regulering
{ "command": "setManual", "thermostat": 2, "mode": "pid" }
Ved skift fra en anden tilstand tilbage til pid eller auto nulstilles PID-regulatoren med den aktuelle temperatur, så den ikke starter fra en forældet værdi.
Fejl hvis thermostat/mode mangler, mode er ugyldig, eller percent mangler/er uden for 0–100 ved mode: "percent".
setAuto

Auto-regulering — trinvis opvarmning med PID-overdragelse

Aktiverer auto-tilstand og konfigurerer grænsetemperaturen. I denne tilstand styres varmeelementet i tre zoner:

ZoneBetingelseVarmeeffekt
Fuld varmeTemperatur < threshold100 %
PID-reguleringthreshold ≤ temperatur ≤ setpointPID-output (0–100 %)
SlukketTemperatur > setpoint0 %
ParameterTypeKravBeskrivelse
thermostatintPåkrævetTermostatnummer (1–3)
thresholdfloatPåkrævetGrænsetemperatur i °C. Under denne grænse kører varmeelementet på 100 %.
setpointfloatValgfriMåltemperatur i °C. Skal være større end threshold. Opdaterer PID-setpunktet. Udelades hvis det eksisterende setpunkt ønskes bevaret.
Eksempel — sæt grænse og setpunkt
{ "command": "setAuto", "thermostat": 1, "threshold": 60.0, "setpoint": 75.0 }
Eksempel — kun opdater grænse
{ "command": "setAuto", "thermostat": 1, "threshold": 55.0 }
Kommandoen aktiverer automatisk auto-tilstand og nulstiller PID-regulatoren hvis der skiftes fra en ikke-PID-tilstand. PID-parametre (kp, ki, kd) konfigureres separat via setPID.
Fejl hvis thermostat/threshold mangler, termostatnummeret er ugyldigt, eller setpoint er angivet men ikke er større end threshold.
setOverride

Global overstyring — fuld varme på alle termostater

Aktiverer eller deaktiverer manuel overstyring for alle tre termostater samtidig (100% effekt). Kan også aktiveres via den fysiske override-knap. Ved aktivering gemmes den aktuelle manualMode/manualPercent for hver termostat, og denne tilstand gendannes automatisk igen når overstyringen slås fra.

ParameterTypeKravBeskrivelse
activeboolPåkrævettrue = aktiver overstyring, false = deaktiver og gendan forrige tilstand
Eksempel — aktiver overstyring
{ "command": "setOverride", "active": true }
Status for overstyringen kan altid ses i feltet "override" i status-svaret.
Fejl hvis active mangler.
lysshow

LED- og display-selvtest

Kører en sekventiel selvtest af alle LED-grupper og TM1637-displayet: alle LED'er lyser samtidig, et Knight Rider-sweep over relæ-LED'erne, sensor-LED'erne løber igennem, termostat-status-LED'erne (grøn → gul → rød pr. termostat), varme-LED'erne, og displayet tæller 0–9 og viser til sidst "bRYG" og "HUS". Ingen parametre. Relæer og varmerelæer påvirkes ikke — kun LED- og display-udgange styres midlertidigt, og normal tilstand gendannes automatisk bagefter.

Eksempel
{ "command": "lysshow" }
Kommandoen er blokerende, mens showet kører, men watchdog'en holdes i live undervejs. Returnerer status når showet er færdigt.
Fysisk betjening
Controlleren kan betjenes direkte via knapper og TM1637-display uden brug af API'et.
Sensorknap

Skift sensor og rediger setpunkt

Sensorknappen styrer hvilket sensor der vises på displayet og giver adgang til setpunkt-editering.

HandlingResultat
Kort trykSkifter til næste sensor (1 → 2 → 3 → 4 → 1). Opdaterer sensor-LED'erne.
Langt tryk (~800 ms)Viser setpunktet for den aktuelle termostat på displayet i 2 sekunder. Sensor 4 har intet setpunkt og viser ----.
Meget langt tryk (~1800 ms)Aktiverer edit-mode: setpunktet vises blinkende. Kun tilgængeligt for termostat 1–3.
Tryk i edit-modeAfslutter edit-mode og gemmer det nye setpunkt i PID-regulatoren.
Edit-mode

Justering af setpunkt via relæknapper

Når edit-mode er aktiv (setpunkt blinker på displayet), bruges relæknap 1 og 2 til at justere setpunktet. Relæknap 3 og 4 virker normalt i edit-mode.

KnapFunktion i edit-mode
Relæknap 1Setpunkt +1 °C
Relæknap 2Setpunkt −1 °C
Relæknap 3 / 4Toggler relæ 3 / 4 som normalt
SensorknapAfslutter edit-mode og gemmer setpunktet
Setpunktet opdateres med det samme i PID-regulatoren når edit-mode afsluttes — ingen genstart nødvendig.
Override-knap

Manuel fuld-varme-overstyring

En dedikeret fysisk knap med tilhørende rød LED. Ved tryk aktiveres fuld varme (100%) på alle tre termostater samtidig — samme funktion som setOverride via API'et. LED'en lyser, mens overstyringen er aktiv. Ved næste tryk deaktiveres overstyringen, og hver termostats tidligere tilstand (manualMode/manualPercent) gendannes.

Fejlsvar
Ved fejl returneres et JSON-objekt med "success": false og en fejlbeskrivelse:
{ "success": false, "error": "Invalid relay" }
